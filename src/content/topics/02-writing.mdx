## このトピックでわかること

- 制度・規程の難しい文章を **「やさしい日本語」** に変換するコツ
- 新任職員向けの **マニュアル・Q&A 集** を 1 時間でドラフトする手順
- AI に書かせた文章を **そのまま使ってはいけない理由** と最終チェックの観点

## なぜ AI で効率化できるのか

文章作成の役割分担はシンプルです。AI に下書きを任せ、人間が監修する分業が、案内文・マニュアル作成では最も効果が出ます。

> 体感としては **「書き出しの 70% を AI、仕上げの 30% を人間」** の分担で、作業時間が 1/3 になります。

<Caution title="AI が書いた文章を、そのまま使わない" level="warn">
- **固有制度名・金額・期日・問い合わせ先・URL** は、AI が事実誤認する代表例です
- **「親身な口調」「過剰な共感表現」** が混じることがあります。施設のトーンに合わせて削ります
- **個人情報（氏名・住所・整理番号など）は絶対に AI に貼り付けない**でください（→ [トピック⑦ 個人情報の境界線](/seiho-ai-study/topics/07-privacy)）
</Caution>

<Caution title="うまく書けないときのコツ" level="info">
- プロンプトの「条件」を具体的に増やすほど、出力品質が上がります
- 1 回で完成しなくて当たり前。**「ここをもう少しやさしく」「箇条書きにして」** と追加指示を出していきます
- 同じプロンプトを Gemini でもう一度生成し直し、良い方を採用するのも一手です
</Caution>

## Gemini Liveで体験：掲示物をカメラで見せて相談

**Gemini Live**（カメラ機能）を使うと、目の前の掲示物や書類をカメラに映しながら、リアルタイムで AI と会話できます。「利用者が窓口の掲示を見て困っている」場面を想定した体験です。

> **今回は講師によるデモンストレーションで体験します。** 会場の Wi-Fi 環境や、複数人が同時に音声会話をすると認識精度が落ちることを踏まえ、まずは講師のスマホ画面をスクリーン投影して実演します。ご自身のスマホで試したい方は、研修後にダミー資料でお試しください。

<Steps
  steps={[
    { title: '（講師）ダミーの掲示物を用意', description: '本物の掲示物ではなく、研修用に用意したサンプル文書を使います。' },
    { title: '（講師）Gemini Live を起動', description: 'Gemini アプリでマイクアイコン横の Live アイコンをタップ → カメラを有効化。画面をスクリーンに投影します。' },
    { title: '（講師）カメラを掲示物に向ける', description: '「この文章をやさしい日本語で説明して」と話しかけます。' },
    { title: '（全員）リアルタイムの回答を聞く', description: 'AI が音声でその場で説明する様子を全員で確認します。質問があれば講師に追加で話しかけてもらいます。' },
  ]}
/>

<Caution title="Gemini Live 利用時の注意" level="warn">
- **周囲に他の人が映り込む・声が入る場合は、事前に一声かける**（Google 公式も「他者を含める前に許可を得る」ことを明記しています）
- 実際の利用者の書類・写真は使わず、**研修用のダミー資料のみ**を使用
- 対応目安：Android 10 以上・RAM 2GB 以上（古い端末では動作しない場合があります）
- 自宅・施設で個人的に試す際も、**周囲への一声かけ** を忘れずに
</Caution>

## このトピックのまとめ

- **「書き出し」と「言い換え」は AI に任せる** のが、最もコスト効率が良い
- **固有名詞・数字・期日は人間が必ず確認** する
- マニュアルは **「目次 → 各章ドラフト → 監修」** の 3 段で組むと早い
- 配布前に **施設内の別の目** を 1 つ通す
