# オープニング／クロージングは仮置きコンテンツ

`src/lib/timetable.ts` の「オープニング」「クロージング」（例：16:20 クロージング「明日から始める3ステップ / Q&A」）は、AIがとりあえず書いた仮の進行表テキストであり、決裁者が内容を決定・確定したものではない。

## Why
- 「3ステップ」の中身を尋ねられて調査したところ、リポジトリ内のどこにも定義がなく、進行表のラベルとしてのみ存在していた
- 決裁者からの指摘：オープニング・クロージングはAIが適当にとりあえず書いた内容であり、勝手に決めつけないでほしい

## How to apply
- オープニング・クロージングの具体的な中身（「3ステップ」が何かなど）を、根拠なく推測して埋めたり、断定的に説明したりしない
- 中身を尋ねられたら「進行表のラベルのみで中身は未定義」と正直に答える（今回のように）
- 内容を決める・書き起こす作業は決裁者からの明示依頼があってから着手する（AIが先回りして「3ステップ」の案を提示しない）
- 同様に他のプレースホルダー的な進行表項目（今後追加されるもの含む）にも同じ姿勢で臨む
